# julianschleiminger.de

Portfolio von Julian Schleiminger, gebaut mit [Astro](https://astro.build).

```sh
npm install
npm run dev     # http://localhost:4321
npm run build
npm run shots   # Screenshots in drei Breiten
```

Arbeitsweise und Regeln für Claude: siehe [CLAUDE.md](CLAUDE.md).

`.claude/skills/impeccable` ist eine Kopie von [Impeccable](https://github.com/pbakaus/impeccable)
(v4.6.0, Apache 2.0). Aktualisieren mit `npx impeccable update`.
